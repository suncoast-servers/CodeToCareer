# Short: first SQL

Lesson: https://codetocareer.org/path-03-sql/01-select/

## Hook (15 seconds)

SQL starts as one question: show me the emails.

## Three beats

1. SELECT chooses columns.
2. COUNT counts rows.
3. ON CONFLICT skips a duplicate email.

## On screen

```sql
SELECT email FROM lab.customers;
```
