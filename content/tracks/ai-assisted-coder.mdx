## The rule

Use the model. Read the diff. Refuse code you cannot explain. The industry nickname is vibe coding. The standard here is that you can still teach the code back.

## Do this, in order

1. [Path 0](/path-00-setup/), especially [Learn with AI](/path-00-setup/learn-with-ai/)
2. [Coder drills](/path-02-python/)
3. [Spec, diff, refuse](/path-ai/)

## Certificate

`ctc-ai-assisted-dev` means you practiced that discipline. It is not a prompt trophy.

## Not a substitute for

[Data engineer](/tracks/data-engineer/) pipelines. It is how you work while you learn them.
