## Outcome

You can fix `average` so it returns the mean, and returns `None` for an empty list.

## Theory

A bug is a wrong assumption that still runs, or a crash. Read the check's message, then the line it points at. Change one thing and run again. Empty input is a normal case, not a surprise.

## Do this

`labs/exercises/path-02-python-05/average.py` is wrong on purpose. Run the check, read the failure, fix it, run the check again.
