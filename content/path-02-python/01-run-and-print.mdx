## Outcome

You can run `python hello.py` and see `Hello, DE101`.

## Theory

A `.py` file is a list of instructions. `print` writes text to the terminal. The checker compares that text exactly, including spelling and spaces.

## Do this

1. Open `labs/exercises/path-02-python-01/hello.py`.
2. Make it print `Hello, DE101`.
3. From that folder run `python hello.py`.
4. From the repo root run `node labs/check.mjs path-02-python-01`.
