## Outcome

You can open this repo and run `git status` in the editor terminal.

## Theory

An editor changes files. A terminal runs programs. VS Code is free. Cursor is a VS Code-style editor with AI built in. Either one is enough. Affiliate details, if a link is tracked later, stay on [Tools we use](/path-00-setup/tools-we-use/).

## Do this

1. Install [VS Code](https://code.visualstudio.com/) or [Cursor](https://cursor.com/).
2. Install the Python and Docker extensions.
3. Open the repo and run `git status` in the terminal.
