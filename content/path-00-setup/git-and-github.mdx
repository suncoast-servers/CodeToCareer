## Outcome

You have two commits in a learning repo, and you know `.env` does not get committed.

## Theory

A repository is a project plus its history. A commit is a saved snapshot. A branch is a parallel line of work. A pull request proposes merging that line. Secrets in git stay in history even after you delete the file.

## Do this

1. Create a GitHub account if you need one.
2. Set your git name and email.
3. `git init`, add a README, commit.
4. Second commit: `notes/path-0.md` with today's date and one thing you learned.
5. Push to a new GitHub repo.
