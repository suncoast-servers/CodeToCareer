## Outcome

Postgres from the core lab answers `SELECT version();`.

## Theory

An image is a blueprint. A container is a running copy. Compose starts the services listed in a YAML file so your machine matches the lesson.

## Do this

```bash
cd labs/compose/core
cp .env.example .env
docker compose --profile core up -d
docker compose ps
```

Connect to Postgres on `localhost:5432` using `.env.example` and run `SELECT version();`. Stop the stack later with `docker compose --profile core stop` (that keeps your data volumes).
