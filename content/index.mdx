## What this is

**Code to Career** ([codetocareer.org](https://codetocareer.org)) is free, open source (MIT), and built for driven beginners. **Path 0** gets anyone to a working laptop stack; **tracks** point toward roles like **data engineer**, **coder**, or **AI-assisted developer**.

## How to use it

1. [Path 0 — Setup](/path-00-setup/welcome/) (everyone).
2. [Choose a career track](/tracks/) — we recommend **[Data Engineer](/tracks/data-engineer/)** for depth today.
3. Run [labs](/labs/) with Docker on your PC or a Hetzner VPS.
4. Earn a [certificate](/certificates/) and add it to LinkedIn.

## Site & repo

The live site is this repo built with Astro. Deploy to your VPS: [`ops/hetzner/site/`](https://github.com/suncoast-servers/codetocareer/tree/main/ops/hetzner/site).
